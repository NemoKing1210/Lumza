## [1.4.0] - 2026-10-29

### Added

- Open one flyout drawer at a time with a shared height reveal
- Acrylic flyout with the Windows accent colour, resave profiles, fix slider fill

### Changed

- Never poison-panic on the flyout, hotkey, log and window locks

### Documentation

- Refresh flyout screenshots

### Fixed

- Repair a stale autostart path and keep debug builds out of the registry
- Follow the system theme in the flyout backdrop
- Avoid a deadlock between the flyout height glide and fit_flyout
- Drop DDC reads that began before a newer write
- Write settings to disk without holding the read lock
- Rescan again when monitors stay silent after wake-up
- Migrate settings in version order, apply profile before pausing the schedule, export atomically

### Performance

- Keep running monitor workers on device changes that add no monitor
- Run one background HDR refresh at a time
- Rebuild the tray menu and icon only when their inputs change

## [1.0.0] - 2026-10-21

First stable release.

### Added

- Tray app for Windows 11 and 10 (21H2+), x64 and ARM64: flyout with brightness, contrast and volume sliders per monitor, Mica, system theme and accent colour, keyboard and mouse-wheel control.
- DDC/CI over Dxva2 with a worker thread per monitor, write throttling and coalescing, verified capabilities, automatic re-scan on display change, hot-plug, wake from sleep and session unlock.
- Stable monitor identifiers from EDID, friendly names, per-monitor rename, order and visibility.
- Linked sliders with per-monitor min–max calibration, per-feature linking and exclusion of single monitors.
- Profiles with built-in "Day", "Night" and "Games", a profile editor, tray submenu and partial profiles.
- Global hotkeys with a key recorder, conflict reporting and a non-focus-stealing OSD (position and duration configurable).
- Schedule by time or by sunrise/sunset (offline calculation from entered coordinates or a built-in city list), smooth transitions in steps of at least 30 s, pause on manual change, full-screen detection, a 24-hour preview.
- Settings window (General, Monitors, Link, Profiles, Schedule, Hotkeys, Advanced, About), autostart, single instance, a versioned settings file with migrations, recovery from a corrupt file and atomic writes, a cache of the last values for an instant first paint.
- Advanced settings: DDC/CI timing (delays and retries) for fussy monitors, export, import and reset of all settings, quick access to the log folder.
- Russian and English interface; strings in `locales/*.json`.
- Optional update check with signature-verified in-app updates; no telemetry.
- `lumzactl`, a command-line tool for diagnosing DDC/CI.
- NSIS installer (per-user, no admin rights) that removes its autostart entry on uninstall; portable archive; rotating log files (5 × 1 MB).

### Not included

Input source switching, mute and screen power-off (P2), software dimming, auto-profile by process, tray-icon mouse-wheel brightness.
